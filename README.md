RefineDocは、WordのコメントからClaudeまたはGeminiで修正案を作成し、採用した変更をWordの正式な変更履歴として保存するmacOSアプリです。

## ダウンロード・起動

1. `RefineDoc-v1.0.0.zip` をダウンロードして展開します。
2. `RefineDoc.app` をアプリケーションフォルダへ移動して起動します。
3. コメント付きDOCXを開き、設定でClaudeまたはGeminiのAPIキーとモデルを指定します。

対応環境：macOS 15以降、Apple Silicon。API利用には各サービスのAPIキーが必要です。

この配布物はアドホック署名の未公証ビルドです。macOSで起動が制限される場合があります。開発元とダウンロード元を確認した上で、システム設定の「プライバシーとセキュリティ」から起動を許可してください。

## 主な機能

- 日本語、複数コメント、複数run、Unicodeの解析
- Claude / Geminiの修正案、Diff確認、採用・保留
- 採用した修正をWord変更履歴として別名保存
- 元コメントと書式の保持、既存変更履歴との競合停止
- APIキーのmacOS Keychain保存
